# Quickstart: MVP RSS Reader

## Prerequisites

- .NET 8 SDK installed
- A terminal available for running the backend and frontend locally

## Run the backend

1. Navigate to the backend project directory.
2. Run the API project.
3. Confirm the backend starts successfully and exposes the subscription endpoints.

## Run the frontend

1. Navigate to the frontend project directory.
2. Run the Blazor app.
3. Open the local UI address in a browser.

## Validate the MVP flow

1. Enter a feed URL in the input field.
2. Submit the form.
3. Confirm the subscription appears in the list.
4. Add another subscription and confirm both entries are shown.
5. Submit an empty value and confirm the list remains unchanged.

## Expected outcome

The app should start locally, allow subscription creation, and display the current set of subscriptions without requiring feed fetching or persistence.
